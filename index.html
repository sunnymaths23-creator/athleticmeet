Publish website changes to GitHub Pages

Prepare one public data file containing the latest profile names and photographs, house names, results, schedule, announcements, student roster and public registration details. Upload the downloaded file to the same GitHub repository folder as this HTML file.

Important: This button downloads a data file; it does not sign in to GitHub or upload automatically. Never upload passwords, private account data or secret keys. Student login passwords are excluded from this export.

How to publish

  1. Save all edits in Manage profiles and the other Organiser Desk tabs.
  2. Click Download publish data (JSON). The file will be named college-site-data.json.
  3. Open your GitHub repository and choose Add file → Upload files.
  4. Upload college-site-data.json into the same folder as index.html (usually the repository root).
  5. Click Commit changes. Wait for GitHub Pages to deploy, then refresh your website.

Published data is loaded automatically when this website is opened from GitHub Pages, if the JSON file exists beside index.html.
